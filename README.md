# Проект: Анализ и экспорт данных о доставках

Программа предназначена для обработки информации о логистических операциях. Она фильтрует заказы по статусу, ранжирует их по цене и экспортирует топ-доставки в текстовый отчет.

## Функционал программы 
* Фильтрует доставки по минимальной стоимости (`completed_from`).
* Выбирает самые дорогие доставки с ограничением по количеству (`top_deliveries`).
* Экспортирует данные  (`export_top_completed`) в TXT файл.

## Запуск отчета
Для получения полезного отчета (топ-2 выполненных доставок с ценой от 1500) запустите основной скрипт:
```python
export_top_completed(data, min_price=1500, limit=2)
```

## Формат выходных данных (`top_completed.txt`)
Файл отчета сохраняется в корневой директории и имеет следующую структуру:
`Название груза, Цена`

*Если подходящих под условия доставок не найдено, в файл записывается только строка заголовка.*
